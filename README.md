# Lead Generation Automation

This project automates NGO lead data collection and organization using Python. The script collects NGO information such as name, email, website, and location, performs data cleaning using Pandas, and exports the cleaned data into an Excel file automatically.

## Features

* Automated lead collection
* Duplicate removal
* Missing value handling
* Excel export automation
* Email format generation

## Technologies Used

* Python
* Pandas
* BeautifulSoup
* Requests
* OpenPyXL
